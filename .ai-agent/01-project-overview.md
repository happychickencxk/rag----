# 项目概览

## 项目定位

本项目是企业知识库 RAG 问答系统的微信小程序前端。用户通过小程序选择知识库、输入自然语言问题、查看带引用来源的 AI 回答，并对回答进行点赞、点踩或提交纠错。

小程序端定位是轻量问答入口，不承担后台管理职责。

## 核心用户

- 普通员工：查询制度、请假、报销、办公规范和内部 FAQ。
- 客服人员：查询售后规范、退换货政策、产品常见问题，并复制标准答复。
- 技术支持或外勤人员：在移动场景查看产品手册、故障排查步骤和引用依据。

## 核心流程

1. 用户进入小程序。
2. 选择当前知识库。
3. 输入问题并发送。
4. 系统按用户身份和知识库权限检索可访问片段。
5. 后端基于 RAG 流程生成回答。
6. 前端展示 AI 回答、引用来源、置信度或异常状态。
7. 用户查看引用详情、继续追问、复制答案或提交反馈。

## 小程序端范围

必须关注：

- 问答首页和底部输入栏。
- 知识库选择与权限状态展示。
- 引用来源折叠卡片和引用详情。
- 历史会话。
- 点赞、点踩、纠错反馈。
- 我的页中的用户身份和知识库权限展示。
- Loading、Streaming、NoEvidence、LowConfidence、NoPermission、ModelTimeout、SensitiveBlocked、EmptyHistory、EmptyKnowledgeBase 等状态。

明确不做：

- 文档上传与批量管理。
- Embedding、Rerank、LLM 参数配置。
- 权限管理后台。
- 审计日志、系统配置、统计仪表板。
- 多列 Dashboard、左侧导航和复杂筛选器。

## 成功标准

- 页面看起来像微信小程序或企业微信小程序，而不是 Web 后台。
- 问答、引用、反馈链路清晰，引用来源不能被弱化。
- 所有权限和异常状态有明确反馈。
- 代码后续能逐步从模拟数据切换为真实 API。
- 文档能让下一个 AI agent 快速接手，不需要重新猜测项目边界。
